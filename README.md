# AI Gateway · Windows Edition
每家协议不同、额度独立、还时不时限流。传统做法是在客户端里反复切换配置。

AI Gateway 的做法：在本地起一个网关（`http://127.0.0.1:8790/v1`）可以自定义~，
对外只说标准 **OpenAI 协议**，对内自动在多家账号之间调度——

- **一个地址通吃**：任何支持 OpenAI 接口的客户端（Claude Code、Cursor、自研工具…）填上网关地址即可。
- **`model=auto` 智能路由**：不指定模型时自动在可用账号间挑选，失败自动换号、换供应商、换模型，
  全链最多 30 个候选，对你透明。
- **额度榨干**：某家限流/熔断/冷却，流量自动落到还有余量的账号上。

## 核心功能

| 模块          | 能力                                                                          |
| ----------- | --------------------------------------------------------------------------- |
| **多供应商接入**  | Trae / CodeBuddy / 小浣熊 / Loomy / ChatGPT / Antigravity + 任意 OpenAI 兼容自定义供应商 |
| **协议转换**    | OpenAI ⇄ 各家私有协议双向转换，不变量「OpenAI 进、OpenAI 出」（流式 SSE / 多模态 / 图片 / 语音转写）        |
| **智能路由**    | `model=auto` 按均衡/质量/速度三档策略自动组链；路由组支持 7 类条件规则（token 数、图片、时段、星期…）             |
| **高可用调度**   | 账号池 + 两级熔断（供应商级/模型级）+ 并发闸门 + 会话亲和（保住上游前缀缓存）                                 |
| **Web 管理台** | 13 页面板：概览可视化、供应商/账号/模型、智能路由、路由组、网关设置、密钥、调用记录、高级策略、备份与恢复（媒体实测入口已移除，本项目仅做 LLM 转发）                      |
| **可观测性**    | 每次调用落库（模型/耗时/首字延迟/tokens/错误），概览页实时调度拓扑、容量环形图、趋势曲线、最近错误、供应商成功率；`GET /metrics` 暴露 Prometheus 文本指标 |
| **客户端密钥**   | 多把 Key 独立发放，白名单 + 用量限额                                                      |
| **安全**      | 数据 AES-256-GCM 加密落盘、请求脱敏（零宽字符清理）、默认只监听本机；开局域网时「无 Key 调用」自动收敛到本机、CORS 可配白名单 |
| **自动化**     | 每日签到、额度同步、凭证自动预刷新、超期记录清理，全都不用手动管                                            |

## 技术亮点

- **纯本地运行**：单进程 + 托盘，数据全在本机（默认 `%APPDATA%\AIGateway\data`），无云端依赖。
- **双主题色**：浅色/暗黑 ，前端 13 页 + 原生无边框窗口。
- **多实例隔离**：文件锁 + 端口派生，多份数据目录并行运行互不干扰。
- **工程化自检**：壳自测 12 项、core 单测 916 项、13 页 UI 全按钮巡检、114 条接口探针、
  流式保真度差分对照（sha256）、上游故障注入 7 模式、脱敏还原变异测试——每次发版全量跑一遍。

## 快速开始

```text
1. 解压 AI-Gateway-win-x64（或运行安装包）
2. 双击 AI Gateway.exe —— 网关与界面一起拉起
3. 在「供应商」页登录你的账号
4. 客户端接入：
     Base URL: http://127.0.0.1:8790/v1
     API Key:  （网关设置里配置，留空表示不校验）
     Model:    auto 或 具体模型名
```

包体约 51 MB（自带精简 JRE，无需装 Java）；需要 WebView2 Runtime（Win10/11 通常自带）。
